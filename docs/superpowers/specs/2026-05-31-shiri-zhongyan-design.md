## 一句话定位

> 一款基于《十日终焉》（杀虫队队员 著）改编的 **2.5D 等距视角、半开放探索、规则怪谈轮回叙事** 单机游戏，玩家扮演齐夏，在中式都市怪诞氛围的"终焉之地"中，反复经历"十日轮回"，逐步觉醒"回响"能力、破解规则、对抗天龙。

## 1. 项目概述

### 1.1 题材来源
- **原作**：《十日终焉》，作者杀虫队队员，番茄小说 2022.12 ~ 2024.10 连载完结，共 1496 章，约 320 万字
- **改编范围**：第 1 章 ~ 第 110 章（覆盖原作"觉醒弧"：齐夏第一次苏醒 → 第一次离析 → 重生 → 觉醒灵闻 → 接触天堂口）
- **改编原则**：以原作剧情为骨，玩家选择为肉。允许"轻微加法"——新增可探索区域、原创支线、玩家自由度，但不改写主干剧情

### 1.2 项目定位
- **类型标签**：规则怪谈 / 轮回叙事 / 半开放探索 / 推理解谜 / 单机 RPG
- **玩家时长**：单线主剧情 25-40 小时；含支线/重玩约 50-70 小时
- **目标用户**：原作书粉 + 规则怪谈爱好者 + 极乐迪斯科/Disco Elysium 玩家 + 中式恐怖玩家

### 1.3 目标平台与发行（**同人模式**）

**发行模式**：同人作品（非商业、为爱发电）

| 项 | 内容 |
|---|---|
| 商业上架 | ❌ 不上 Steam / App Store 等需要正式 IP 授权的商业渠道 |
| 收费方式 | ❌ 不付费、不广告、不内购；可接受「建议捐赠 / 爱发电」模式 |
| 发布渠道 | itch.io、B 站游戏区、GitHub Pages、独立游戏社区（落樱小镇等）、自建网站 |
| 平台覆盖 | PC（Windows / Mac / Linux）首发 / 移动端（Android / iOS）二期 |
| 作者沟通 | Alpha 前主动联系原作者杀虫队队员，争取**书面默许**（哪怕不是正式授权） |
| 应急预案 | 若版权方反对，准备 1 周内完成全渠道下架；保留源码备份 |
| 未来可能 | 若作品有口碑，可反向找作者谈商业授权（**概率低，不作为预期**） |

## 2. 核心玩法循环

### 2.1 主循环：十日 = 一个 run

```
苏醒 ┐
  │   ┌──────────────────────────────┐
  │   │  Day 1 - Day 10 (一个十日轮回) │
  │   │                              │
  │   │  ┌─ 道城探索（B 风格步行）    │
  │   │  │   ↓                       │
  │   │  │  接受生肖游戏挑战          │
  │   │  │   ↓                       │
  │   │  │  进入副本（C 风格关卡）    │
  │   │  │   ↓                       │
  │   │  │  胜利 → 获得「道」         │
  │   │  │  失败 → 死亡或惩罚         │
  │   │  │   ↓                       │
  │   │  └→ 回道城 / 回面试房间      │
  │   │   ↓                          │
  │   │  Day 10 「离析」 — 全员化为粉末│
  │   │                              │
  │   └──────────────────────────────┘
  │        ↓ 「生生不息」自动重置
  └─ Day 1 of Cycle 2（重回面试房间）
              ↓
       玩家记忆未保留（普通人）
       但**玩家本人保留全部记忆**
       即玩家"知道"上一轮发生了什么
              ↓
       重玩同一场景，新策略，新发现
              ↓
       Cycle 2 死前：觉醒「灵闻」回响
              ↓
       进入 Cycle 3（游戏在此处结束 / 留作续作）
```

### 2.2 玩家每一天的内容（典型）

| 时段 | 玩家活动 |
|---|---|
| 道城自由探索期 | 步行道城腹地、与 NPC 对话、收集情报、买卖物资 |
| 接受挑战 | 在道城各处副本入口选择生肖游戏，单次约 30-60 分钟 |
| 副本中 | 在限定场景内执行规则，期间穿插对话/检定/解谜 |
| 副本后 | 回到道城广场，新觉醒者会触发巨钟鸣响（社交事件） |
| 夜晚 | 回到面试房间整理线索、与队友对话（仅 Cycle 1 早期；后期可在天堂口休息）|

### 2.3 死亡与轮回

- **正常死亡**：副本中死亡 → 该角色失去本轮回参与资格，等待第 11 日重置
- **第 10 日离析**：所有人（包括存活者）化为粉末
- **第 11 日重置**：所有人回到面试房间苏醒
  - **普通 NPC**：失忆，重新开始
  - **玩家（齐夏）**：**保留全部记忆**，包括读过的规则、认识的人、犯过的错
  - **特殊 NPC（已觉醒回响者）**：保留记忆，与玩家共谋

## 5. 关键系统

### 5.1 半开放探索系统（B+C 混合 / "P5 模式"）

- **道城腹地** = B 风格连续步行小型城区，玩家自由行走，撞 NPC 触发对话，每条街都有内容
- **道城其他区域 / 副本** = C 风格独立节点，进入需要"地点切换"过场
- **每天有时间预算**：每个十日 = 10 个游戏日，每日 = 3 时段（上午/下午/夜晚），副本和探索都消耗时段
- **行动选择压力**：玩家做不完所有事，必须做取舍

### 5.2 十日轮回与记忆系统

| 实体 | 离析后是否保留记忆 | 备注 |
|---|---|---|
| 玩家（齐夏） | ✅ 全部保留 | 元游戏知识，重玩有用 |
| 普通 NPC（陈俊南、乔家劲等） | ❌ 失忆 | Cycle 2 重新认识玩家 |
| 已觉醒回响者（苏闪、林檎等） | ✅ 保留 | Cycle 2 起可与玩家共谋 |
| 生肖（人羊张强等） | ✅ 保留 | 知道玩家是"老面孔" |
| 物品 / 道 / 装备 | ❌ 全部清零 | 每个 run 重新积累 |
| 已解锁的"知识"（规则、地图、谜底） | ✅ 玩家心智保留 | 元游戏永久积累 |

### 5.3 回响系统

- **回响**：当玩家或 NPC 在"特定情绪极端状态下死亡"时，可能觉醒一种独特能力
- **觉醒契机**：每个角色有独特触发条件（齐夏=心安、悲伤；乔家劲=想公平对决等）
- **能力效果**：详见 Appendix B（来自原作设定）
- **游戏内呈现**：觉醒时道城广场巨钟鸣响 + 显示屏宣告能力名（社交事件）
- **Ch 110 内可觉醒**：玩家齐夏（灵闻，Cycle 2 末必触发）+ 部分 NPC（按剧情）

### 5.4 道（积分）经济

- **货币定义**：道 = 核桃大小的黄白色眼球状物体（由人的眼球制成的不祥之物）
- **来源**：参与生肖游戏胜利、与 NPC 交易、隐藏宝箱
- **用途**：游戏门票、商店购物、贿赂、赌命
- **谎言**：原作中"集齐 3600 颗道可逃离"是天龙的骗局——玩家在 Ch 110 内不会发现这一点（留作后续剧情）
- **游戏内 UI**：顶栏常驻显示当前道数 + 当日剩余时段

### 5.5 规则面板系统（A 元素核心 UI）

每个生肖游戏入场时弹出**规则面板**，玩家可随时调出：
- 表面规则（生肖明示给所有人）
- 玩家发现的隐藏规则（通过尝试/对话累积）
- 笔记（玩家手写笔记或自动汇总）
- 跨轮回保留（Cycle 2 重玩同一游戏时，规则面板已部分填充）

### 5.6 时间与日程系统（"游戏内时间 + 本地时间显示" 混合模式）

**核心规则**：

| 维度 | 实现 |
|---|---|
| **时间推进** | 完全由玩家行动驱动（游戏内时间），动作消耗时段，**不与现实时间挂钩** |
| **时段划分** | 每个游戏日分 3 个时段：上午 / 下午 / 夜晚 |
| **UI 显示** | 顶栏同时显示「游戏内日期（如：Cycle 1 · Day 3 · 下午）」+ 「**真实本地时间**（如：14:32）」 |
| **NPC 日程** | NPC 在游戏内时段（不是本地时间）的不同地点出现，**严格按原作描述的章节进度展示**：哪一章出现哪个 NPC、在哪个地点、做什么，全部参照原文。不做原创日程 |
| **日记系统** | 玩家做关键事件时自动生成"日记条目"，使用**真实本地日期**作为日记本上的日期戳，营造"现实流逝"感 |

**为何这么设计**（决策理由）：
- 玩家完全控制游戏节奏（可一口气连刷）✅
- 通过"本地时间显示"和"本地日期日记"给予**仪式感**和**沉浸感**
- 避免动森式"现实时间锁"对硬核玩家的劝退

**游戏内 UI 范例**：

```
┌──────────────────────────────────────────────┐
│  Cycle 1 · Day 3 · 下午   |   2026-05-31 14:32   |  💧 23 道  │
└──────────────────────────────────────────────┘
```

### 5.7 对话与 UI 交互系统（无配音，纯文字 + 对话框）

**核心约束**：

- ❌ **不做配音** —— 全文字驱动，节省成本，便于本地化
- ✅ **对话框 UI** —— 经典 RPG/AVG 风格：角色头像（半身像）+ 名字 + 文字气泡 + 选项按钮
- ✅ **检定/选择** —— 关键节点弹出选项框，**支持骰检定**（A 元素借鉴极乐迪斯科）
- ✅ **环境音/UI 音效** —— 保留（脚步声、环境氛围、UI 反馈、关键事件音）
- ✅ **背景音乐（BGM）** —— 保留（道城主题、副本主题、紧张/平静切换）

**对话框 UI 范例**：

```
┌────────────────────────────────────────────┐
│  ┌──────┐                                  │
│  │ 头像  │  陈俊南                          │
│  └──────┘  "齐夏，你确定要赌命？这不像你。"  │
│                                            │
│  ┌─ [a] 我有把握                           │
│  ├─ [b] 你别管，跟我来                     │
│  └─ [c] 沉默                               │
└────────────────────────────────────────────┘
```

### 5.8 原作内容遵循原则

**所有以下内容必须严格遵循原作小说，不做原创改动**：

| 内容类别 | 遵循原则 |
|---|---|
| 道城地理布局 | 街道、地标、子区域的相对位置严格按小说描写 |
| 副本规则（生肖游戏） | 门票、奖励、惩罚、表面规则、隐藏规则 100% 按小说原作 |
| 角色身份/能力/回响 | 不修改主要角色的核心设定 |
| 阵营组织架构 | 生肖体系、神兽、天堂口等组织关系不变 |
| 关键剧情转折 | Cycle 1 死亡、Cycle 2 觉醒等核心节点不变 |

**允许的"加法"范围**（来自原作 *不足* 的地方做合理补全）：

- 道城**未命名街道** → 由开发者自由命名（保持中式都市怪诞氛围一致即可）
- 道城**未描述地标摆位** → 由开发者发挥（保持中式风格、合理地理逻辑）
- 副本**未描述的视觉细节** → 由开发者发挥（房间装饰、NPC 站位、道具摆放）
- **支线 NPC 对话台本** → 全部原创（小说只描写主线对话，支线由开发者补全）
- **玩家自定义齐夏的外观** → 完全自由

**开发者补全的统一原则**（避免风格漂移）：
1. 必须保持"赛博中式都市怪诞"美学一致
2. 不与原作明确描述的内容冲突
3. 任何疑问优先回归原文重读，不臆造
4. 重要补全（如街道命名）需在主创内部 review 一致

**严禁**：
- 改副本规则数值（破坏原作平衡）
- 改主线剧情转折（破坏改编忠诚度）
- 加入超出原作世界观的物品/技能（破坏统一性）
- 加入原作未出现的"快进通关"等机制（详见 §5.9）

### 5.9 第二轮回的"重玩"体验策略

**核心决策**：完全尊重原作，**不做规则变体 / 不做动态难度 / 不做快进选项**。

**避免疲劳的方式 = 叙事层面差异，而非机制层面差异**：

| 维度 | Cycle 1 | Cycle 2 | 差异来源 |
|---|---|---|---|
| 副本规则 | 学习 | 同样规则 | 相同（按原作） |
| 玩家齐夏的记忆 | 空白 | ✅ 完整保留 | 玩家**可做完全不同决策** |
| 普通 NPC（陈俊南等） | 初识 | ⚠️ 失忆，但齐夏记得 | "**错位感**"是 Cycle 2 的核心情绪戏 |
| 已觉醒回响者 | 不存在 | ✅ 与玩家共谋 | 新的盟友关系 |
| 主线剧情 | 探索式 | 推理式 → 觉醒灵闻（高潮） | 剧情进入深水区 |
| 玩家心智 | 一无所知 | 知道隐藏规则 | 元游戏积累 |

**这是原作的精髓**：重玩感来自"角色成长 + 玩家成长"，不是"游戏机制变化"。

**⚠️ 承担的副作用**：部分玩家会感觉某些副本是"重复内容"。这是按"完全尊重原作"必须接受的代价。

**应急预案**（如未来 playtest 发现疲劳严重）：
- 可补加"快速重玩已熟悉副本"的可选模式（玩家自愿启用，不强制）
- 但**不在 v1.0 中实装**，先按"完全尊重原作"发布，依据玩家反馈再迭代

### 5.10 物理碰撞设计原则

**所有可见且可与玩家空间互动的实体必须有物理碰撞体**。这条原则适用于本项目所有后续开发。

**适用对象**：

| 实体类别 | 节点结构 | 备注 |
|---|---|---|
| 玩家（齐夏）| `CharacterBody2D + Sprite2D + CollisionShape2D` | 已实现 |
| NPC（其他囚徒、生肖、原住民、癫人）| `CharacterBody2D + Sprite2D + CollisionShape2D` | 即便静止 NPC 也用 CharacterBody2D，方便后续加 AI 移动 |
| 建筑物（房屋、墙、家具、地标）| `StaticBody2D + Sprite2D + CollisionShape2D` | 永远不动用 StaticBody2D 性能更好 |
| 可拾取物 / 互动触发区 | `Area2D + CollisionShape2D` | 触发器而非阻挡 |
| 副本入口 | `Area2D + CollisionShape2D` | 进入触发场景切换 |

**不适用对象**：
- 纯装饰（远景、UI、粒子特效、屏幕外远景）

**碰撞形状选择**：
- **圆形**（CircleShape2D）：人物、可拾取物
- **矩形**（RectangleShape2D）：建筑物地基、墙
- **凸多边形**（ConvexPolygonShape2D）：等距菱形地基（高级 polish）

**碰撞位置原则**：
- 所有 collision 节点的 `position` 应放在 **sprite 的"脚部"**（视觉底部），避免玩家撞到"屋顶"或"头顶"的怪异感
- 例：48×80 建筑 sprite，collision offset y=26 让矩形落在"屋基"高度；32×48 人物 sprite，collision offset y=14 让圆形落在"脚下"

### D.1 说谎者（人羊·张强）

| 字段 | 内容 |
|---|---|
| 出现章节 | Ch 1~5（首个面试游戏） |
| 主理生肖 | 人羊 / 张强（戴山羊头面具） |
| 场地 | 面试房间·围桌 |
| 参与人数 | 10 人围桌 |
| 门票 / 奖励 | 无门票 / 通关获得离开资格 |
| **表面规则** | 10 人中有 1 名「说谎者」（即人羊本人或被指派的伪装者）。全员需通过对话推理找出 TA，最终将名字写在纸上**意见统一**指向同一人才算胜 |
| **隐藏规则** | ①「说谎者」并不一定是字面意义"说假话的人"——而是被规则"设定为靶子"者，可能 TA 没说过谎 / ②"意见统一"意味着 10 票必须**全部**指向同一人；任何分歧都会判全员失败 |
| **典型通关方式** | 玩家齐夏需主导讨论节奏：① 引导大家分享背景以筛选嫌疑 ② 故意暴露自己的部分信息建立信任 ③ 关键时刻用心理学优势锁定"被规则设定的靶子"（而非"撒谎的人"）④ 说服全员一致指向 TA |
| **失败惩罚** | 全员被人羊"制裁"——典型情况下死亡，少数被夺取理智沦为癫人 |
| 关键 NPC | 人羊·张强（白羊系徒弟，齐夏旧识，但 Cycle 1 内齐夏失忆） |

### D.2 是与非 / 两颗药丸 / 狡诈之蛇（人蛇）

| 字段 | 内容 |
|---|---|
| 出现章节 | Ch 6~12 |
| 主理生肖 | 人蛇（伪装为面试官出场） |
| 场地 | 面试房间·密室（人蛇的房间） |
| 参与人数 | 单人 vs 人蛇 |
| 门票 / 奖励 | 无门票 / 通关有资格进入下一关 |
| **表面规则** | 玩家在 **3 次回答 / 提问** 内让人蛇觉得「有趣」，否则死亡 |
| **典型题目** | ①「是与非」（自指悖论） ②「两颗药丸」（10 天 20 粒混合药丸的统计问题） ③「飙车遗产」（兄弟交换车辆悖论） ④「幸存者偏差」 ⑤「无限猴子定理」（全员暴动逃生） ⑥「协同攻击难题」 |

| **失败惩罚** | 人蛇"啃咬"——典型死亡 |

### D.11 关卡通用机制与系统

适用于所有副本：

| 机制 | 描述 |
|---|---|
| **赌命系统** | 玩家可主动向生肖发起赌命，规则可临时修改（如黑白棋的真假眼镜规则就是赌命后追加的） |
| **门票/退款** | 无奖励的通关常返还门票（如仓库寻道）|
| **隐藏规则触发条件** | 多数游戏的隐藏规则由"玩家行动"或"赌命"触发，被动等待无法发现 |
| **生肖永不回响** | 戴上面具的生肖不可使用仙法（回响），玩家须利用这条对抗 |
| **死亡 vs 离析** | 副本中死亡 = 该 Cycle 失去参与者资格；第 10 日离析 = 全员死亡（包括胜利者） |
| **记忆传承** | Cycle 1 玩家死亡的副本经验，Cycle 2 玩家仍记得 |
