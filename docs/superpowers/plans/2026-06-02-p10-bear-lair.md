# P10 · 地牛 · 黑熊地下室（第 4 个生肖关）

**目标**：第 4 个生肖关卡，对应原作 Ch 36-38「地牛 · 黑熊地下室」。验证"AI 巡逻 / 体力槽 / 多波次事件"模板，给后续 P11+ 关卡再多一个抄板可参。

**Scope**：单人极简版（玩家 vs 黑熊咆哮事件），跳过原作的"20 人募集 + 黄绿队分队"以适应单机。**保留**原作经济反差（高门票 / 高奖励）和"地牛比人系列更高级"的设定。

---

## 玩法机制（原创）

```
入场：花 1 道当门票（地牛 NPC 在玉城东区）
场地：地下室（暗色调，3 根铁柱 + 中央铁板）
时限：90 秒（原作 10 分钟，游戏化压缩）
体力：满 5 点

事件循环（每 12 秒一轮）：
  [0-9s]  自由活动（铁柱不锁，玩家可移动）
  [9-12s] ⚠️ 预警闪屏 3 秒 + Toast "黑熊准备咆哮"
  [12s+] 💥 咆哮判定：
           · 站在任意铁柱旁（半径 60 像素内）→ 安全
           · 不在铁柱旁 → -1 体力

事件总轮数：90 / 12 = 7-8 轮咆哮
  - 玩家若全程在铁柱旁 → 0 伤害 → WIN
  - 体力归零 → LOSE（被熊抓）

经济：
  门票：1 道
  WIN：+10 道（净 +9，匹配原作"通关人数 = 奖励"的反差感）
  LOSE：失去门票（不死，类似人鼠普通模式）

道具兼容：
  - 桃木防御符：LOSE 时自动消耗 → 重置体力 5、重新计时
  - 休息券：不适用（仅玉城用）
  - 灵闻笔记 / 线索袋：在 BearLair 暂不生效（留 P10.5）
```

## NPC

- **眼镜男（小眼镜）**：玉城东区某处拉客。"我们找到个好游戏，要不要去赚点道"
- **地牛**：地下室门口主持人。戴干净的水牛面具，黑西装，介绍规则
- **黑熊**：场地内的 AI 角色（不可对话，仅作为咆哮源 sprite）

## 设计要点

- **铁柱 = 安全锚**：玩家学会"咆哮预警时找铁柱"，玩多了能 0 伤通关
- **预警 3 秒**：足够玩家从场地任意点跑到最近铁柱（避免不公平）
- **体力槽是 HUD 核心**：让玩家有"还能扛 2 次"的紧张感
- **黑熊只作 sprite + 视觉震慑**：不做真 AI 追击（工作量 +5x）

## 风险

- 体力槽和咆哮节奏需要 playtest 微调（太宽松没紧张感、太苛刻劝退）
- 场地大小要让玩家来得及跑到铁柱（建议 480×320 像素，铁柱呈三角分布）
- 跟人鼠关入口"挤"在玉城东区 → 把地牛放更远（南区天堂口附近？）
