# P4：「说谎者」生肖游戏关卡 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal**：实现原作 Ch 1~5 的「人羊·说谎者」游戏作为**第一个端到端可玩切片**。玩家进入面试房间 → 与 5 名其他囚徒对话收集线索 → 推理谁是"说谎者" → 提交答案 → 胜利或失败结算。

**Scope（精简版 MVS）**：
- ✅ 新场景 `interview_room.tscn`
- ✅ 围桌格局 + 玩家 + 5 名其他囚徒（陈俊南 / 乔家劲 / 张丽娟 / 苏闪 / 林檎）+ 人羊·张强（主理人）
- ✅ 每名 NPC 1 段对话（自我介绍 + 一两句关键线索）
- ✅ 投票 UI：玩家选择指认对象
- ✅ 胜利/失败结算（基于硬编码"正确答案"）
- ❌ **不做**：原作的 10 人（仅 5+主理人）、多轮对话、AI 推理、复杂分支
- ❌ **不做**：场景切换 from TestWorld（把面试房间设为新 main scene；TestWorld 保留作 sandbox 测试用）

**Architecture**：
- **新场景**`src/scenes/world/interview_room.tscn`
- **关卡控制器**`LiarGameController` Node：管理游戏状态、监听玩家提交、判断胜负
- **投票 UI**`VotePanel` CanvasLayer：弹出式选项列表
- **5 名 NPC** 用占位贴图（重用 player_placeholder + 不同 modulate 颜色）
- **对话台词**：AI 占位版（待 P3.5③ 完成后替换为原作 Ch 1~5 真实台词）

**Tech Stack**：复用 P2 对话系统 + P3 存档 + P3.5 Toast + Godot 4.6.3 内置节点。

**遵循既定原则**：
- TDD（核心逻辑写测试）
- 物理碰撞（5 NPC + 1 主理人 + 桌子都有 collision）
- 对话期间禁用玩家移动（P3.5 已实现）

**预估**：约 6 个 task。

## Task 2：LiarGameController + 单元测试（TDD）

**Files**:
- Create: `src/scripts/liar_game/liar_game_controller.gd`
- Create: `tests/unit/test_liar_game_controller.gd`

- [ ] **2.1 写测试**：测试 4 个核心行为
  - 默认状态：未提交、game_state == PLAYING
  - 调用 `submit_vote(npc_id)` 后状态变 SUBMITTED + emits signal
  - 投票命中 LIAR_ID → result == WIN
  - 投票未命中 → result == LOSE
  - 投票完后再次 submit 被忽略

- [ ] **2.2 实现 LiarGameController**

```gdscript
class_name LiarGameController
extends Node

signal vote_submitted(target_id: String, result: Result)

enum State { PLAYING, SUBMITTED }
enum Result { NONE, WIN, LOSE }

@export var liar_target_id: String = ""   ## 由场景或 Inspector 设置；默认用 LiarNpcId.LIAR_ID
var state: State = State.PLAYING
var last_result: Result = Result.NONE
var last_voted: String = ""

func _ready() -> void:
    if liar_target_id == "":
        liar_target_id = LiarNpcId.LIAR_ID

func submit_vote(target_id: String) -> void:
    if state == State.SUBMITTED:
        return
    state = State.SUBMITTED
    last_voted = target_id
    last_result = Result.WIN if target_id == liar_target_id else Result.LOSE
    vote_submitted.emit(target_id, last_result)
```
