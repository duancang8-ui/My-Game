# P8 · 人鼠 · 仓库寻道（基础版）

**目标**：第 3 个生肖关卡，对应原作 Ch 30-33「人鼠 · 仓库寻道」。让玉城 → 关卡 → 玉城的循环范式真正完整（之前只有面试房一条路）。

**Scope**：基础版（普通模式 + 隐藏解法 + 翻箱 + 时间限制）。**赌命模式 + 朱雀处决演出**留作 P8.5。

---

## 玩法机制（原作事实，可直接照搬）

| 项 | 设计 |
|---|---|
| 主持 | 人鼠 NPC（戴鼠面具的年轻女人） |
| 门票 | 1 个「道」 |
| 时限 | 5 分钟 |
| 场景 | 小型仓库 + 6-8 个货架/箱子 + 白炽灯开关 |
| 表面规则 | 5 分钟内找到 1 个「道」并带出来 |
| 真相陷阱 | 「道」根本不在房间里 — 在人鼠口袋里 |
| 解法 | 走到门口和人鼠对话，选「（伸手摸她的口袋）」 |
| 关键暗示 | 人鼠言语 + 行为里有 3 处可观察破绽 |

## 3 处破绽（玩家自己拼）

1. **她每次强调「现在」房间里有一个「道」**（暗示马上就没了）
2. **她在房门关上后秒知道你赢/输了**（隔门预知 = 她知道结果）
3. **「鼠类」≠ 老鼠**，鼠类里**仓鼠**会把东西藏嘴里 / 颊袋里

第 3 点最关键：游戏化为仓库门口贴一张纸条「请爱护展品 · 仓鼠协会赞助」，玩家走近按 E 触发齐夏 1 行内省：「仓鼠……不是老鼠那种翻找。是藏东西。」

## 流程

```
玉城东区 → 走近"人鼠"NPC → 对话
  ↓
人鼠介绍游戏（自述 + 规则）→ 选项：
  ① 付 1 道，开始
  ② 算了，先看看（关闭对话）

① 后切场 → rat_warehouse.tscn
  ↓
玩家进场，5 分钟倒计时启动
  ↓
玩家可：
  - 翻 6 个箱子（按 E 触发"这箱只有罐头/旧衣..."）
  - 按门口的灯开关（关灯/开灯，呼应原作"道应该发光"陷阱）
  - 走到人鼠（门口站桩）按 E：
    · 在第 1 次进入时只能寒暄
    · 在玩家观察了"仓鼠协会"贴纸后，对话出现「（伸手摸她的口袋）」选项

→ 选「摸口袋」= WIN
  ↓ 拿到「道」，+1 净奖励，回玉城东区入口
  
→ 5 分钟到 = LOSE
  ↓ 失去 1 道，回玉城东区入口

→ 任何时刻按"离开"门 = 退出（失去门票 1 道）
```

## 数值

- 门票：1 道（从 GameState.dao_count 扣）
- WIN 奖励：+2 道（净 +1）
- LOSE / 离开：失去门票（无额外惩罚）
- 限时：300 秒（5 分钟）

## 解法触发条件

为了不让玩家"瞎试"，需要他**真的观察一遍**：
- 必要：触发过"仓鼠协会"贴纸的内省
- 推荐：跟人鼠至少寒暄过一次（让他听清"现在这个房间有一个道"）

满足条件后，再去和人鼠对话，会出现选项：
- `（伸手摸她的口袋）` → WIN
- `（再看看）` → 关闭对话
