## 关键设计点

### c1 Seed
- `LiarGameController.@export random_seed: int = 0`（0 = 真随机；非零 = 复现）
- 当前 `LiarGameController` 已无 hint 随机，但加 seed 支持后续可控（如：未来 b1 微表情触发模式可复现）
- 同样加到 `RotateGameController`

### c3 道币
- `LiarGameOrchestrator._on_win_cinematic_done` 内：`GameState.add_dao(5)` + Toast
- `RotateGameOrchestrator` 胜利同样 `+3 dao`
- `LevelHUD` / `RotateGameHud` 右下角加 `🪙 X` Label，监听 GameState polling

### b4 光环 + 浮动 prompt
- `PlayerInteractor.interactable_entered` 已存在 → 在 Interactable 节点 _ready 时挂一个 ColorRect/Sprite2D "光环"占位（黄色半透明圆，默认 `visible = false`）
- 玩家 enter 时 visible = true，exit 时 false
- 加一个 `InteractablePrompt` CanvasLayer（autoload 或场景级别）：当 PlayerInteractor 有 entered 的 Interactable 时，在屏幕底部居中显示 prompt_text；离开时隐藏

### b1 NPC 微表情
- 新增 `NpcMoodBubble` 节点（贴在 NPC sprite 上方）
- 内置 4 个 emoji：···、？、💭、👀
- `_process` 内累计随机间隔（5-15s）切换显示一个气泡 0.8s 后隐藏
- 加 `@export enabled: bool = true`，方便测试关掉

### P4.9 观察点
- 在 `LiarRoomBuilder` 加 3 个新的 Interactable（DIALOGUE 类型，dialogue_id 以 `liar_clue_xxx`）：
  - `liar_clue_wall`：墙边方格 → 短对话"齐夏数方格：地面 4x4，墙面 3x4。这屋子约 48 立方米。"
  - `liar_clue_clock`：座钟 → 短对话"已经一个小时了。钟还在走，但门一直没出现。"
  - `liar_clue_corpse`：尸体 → 短对话"伸手摸了摸——已经没有体温了，可血还没干。这不合常理。"
- `GameState.observed_clues: Array[String]`，每观察一个 +1
- 观察够 3 个 → 触发"齐夏灵光闪现"特殊对话："这个房间根本装不下九个活人的呼吸……"（不直接说"投人羊"，让玩家自己拼出来）

### a4 笔记本
- 新增 autoload `Notebook`（CanvasLayer，layer=70）
- 维护 `entries: Dictionary[String, String]`（key=NPC 名字，value=玩家收集到的关键事实）
- `DialogueController._on_dialogue_ended` 时根据 dialogue_id 写入对应事实：
  - `liar_li_shangwu_v2` → 写入"李尚武：内蒙刑警，被勒颈"
  - `liar_lin_qin_v3` → 写入"林檎：注意到我们没缺氧"
  - …
- 玩家按 `N` 打开笔记本，显示所有 entries
- 投票面板打开时也自动显示（让玩家投票时不用记 NPC 故事）

### P4.8 雨后春笋同房间
- `LiarGameOrchestrator._on_win_cinematic_done`：
  - 不再 spawn 通往玉城的出口
  - 改为：座钟变 1:05（视觉提示）+ 等 0.5s + 触发"人狗远叫声"短过场对话
  - 紧接着初始化 `RotateGameController` + 显示 RotateGameHud
  - 桌子从 8 个 NPC 围坐 → 转桌玩法
  - 玩家走到桌子前按 E → 转桌 +1（按 N 次累计到 100）
- 转桌赢了 → spawn 通往玉城的出口
- 转桌输了 → ResultScreen + retry 整套（重玩需要 retry 整套关卡，原作里失败就死）

注意：P4.8 是最大改动，会修改：
- `LiarGameOrchestrator`（胜负流程接驳新关）
- `InterviewRoom.tscn`（加 RotateGameController + RotateGameHud + IntroCutscene）
- 老 `rainy_field.tscn` 可保留但不再是入口（万一日后想"独立小游戏模式"还能用）
