## 我建议你回来后选的下一步

按"边际收益"排序：

```
1. 调参（30 分钟）— 黑熊关 5 ❤️/12s/60px 是 first pass，你 playtest 后可能想改
2. P10.5（1-2 小时）— 灵闻笔记/线索袋在黑熊关也生效
3. M2.5 设置面板（1-2 小时）— 音量条 + 全屏切换 + 难度档
4. M1 第 5 个生肖关（3-4 小时）— 候选「人鸡 · 谁是凶手」推理关
5. 美术 sprint（独立 2-3 周）— 等 5-6 关稳定后
```

我个人的建议：**1 → 3 → 4 → 美术**。

理由：
- 调参最便宜立即提升体验
- 设置面板让玩家能自调音量，减少未来反馈
- 第 5 关刚好凑齐 5 关 = 美术 sprint 触发条件
- 4 关 + 设置 + 教学已经是"alpha 玩家测试"的最小可玩品

## 一些你可能会注意到的"小漏"

- **主菜单**目前没有 Logo 图（只有文字标题）—— 美术 sprint 才出
- **主菜单"继续"按钮**直接 `change_scene_to_file`（不走 SceneManager fade）—— 避免双层 fade，但少了过渡感
- **教学提示**用 Toast 弹（5 秒消失），看不到也没事（笔记本里有快捷键完整列表）
- **赌命模式**目前 RatGameController 接口里没有"WIN 时给不同奖励"的字段，奖励逻辑在 Orchestrator 里 `+5 vs +2`
- **AudioManager**日志会刷得很快（每事件一条）— 调试时方便，正式发布要清掉或换 push_warning 抑制

## 我相信你会先注意到的 bug 候选

playtest 时如果出问题，按概率排：

1. **教学 Toast 重叠**：同一帧 2 个场景切换可能触发 2 个提示 — 没见过但理论上可能
2. **主菜单"继续"读不到旧存档**：因为 P9/P10 加了新字段（sniffed_npcs / tutorial_seen / rat_bet_mode）。如果你之前用 F9 存的档没这些字段，会用默认值——不致命，但可能"感觉怪"
3. **黑熊关咆哮判定时机错过半帧**：因为 `_phase_elapsed += delta` 浮点累积，可能比 12s 多/少一帧——影响很小
4. **AudioManager 自动监听 SceneManager.scene_change_finished**：TutorialHints 也监听了这个信号，两者顺序未定 — 但都是只读，应该无问题
